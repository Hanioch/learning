===============================================================================
  LEARNING — COMMENT LANCER LE PROJET
===============================================================================

Tout se fait dans un terminal, depuis le dossier du projet :

    cd chemin/vers/learning


-------------------------------------------------------------------------------
  CE QU'IL FAUT AVOIR INSTALLE AVANT
-------------------------------------------------------------------------------

  - Node.js version 20 ou plus (verifie avec :  node -v  )
  - npm ou pnpm, au choix
  - Une cle API Anthropic, a creer ici :
        https://platform.claude.com/settings/keys


-------------------------------------------------------------------------------
  PREMIERE FOIS : 3 COMMANDES
-------------------------------------------------------------------------------

  1) Installer les dependances

        npm install

     ou, si tu preferes pnpm :

        pnpm install


  2) Creer le fichier de configuration

        cp .env.example .env

     Sur Windows en PowerShell :

        copy .env.example .env

     Ouvre ensuite .env et remplace la ligne :

        ANTHROPIC_API_KEY=sk-ant-...

     par ta vraie cle. Ne partage jamais ce fichier, il n'est pas versionne.


  3) Demarrer le site

        npm run dev

     Puis ouvre :   http://localhost:3000

     Pour arreter : Ctrl + C dans le terminal.

  Il n'y a pas d'etape de base de donnees. L'historique est un simple
  fichier JSON, cree tout seul au premier texte genere.


-------------------------------------------------------------------------------
  LES FOIS SUIVANTES : 1 SEULE COMMANDE
-------------------------------------------------------------------------------

        npm run dev

  Refais "npm install" uniquement apres un "git pull" qui change les
  dependances, ou si tu reclones le projet.


-------------------------------------------------------------------------------
  TOUTES LES COMMANDES DISPONIBLES
-------------------------------------------------------------------------------

  npm run dev          Serveur de developpement (rechargement automatique).
                       C'est celle que tu utilises au quotidien.

  npm run build        Construit la version optimisee du site.

  npm start            Lance la version construite (mode production).
                       Necessite "npm run build" avant.

  npm run lint         Verifie le style du code (ESLint).

  npm run typecheck    Verifie les types TypeScript.


-------------------------------------------------------------------------------
  OU SONT STOCKES LES TEXTES GENERES
-------------------------------------------------------------------------------

  Dans le fichier :   data/generations.json

  C'est un simple tableau JSON, lisible et modifiable a la main. Il est
  cree automatiquement au premier texte genere.

  - Pour sauvegarder ton historique : copie ce fichier.
  - Pour repartir de zero : supprime-le (ou supprime tout le dossier data).
  - Il n'est pas envoye sur GitHub (il est dans .gitignore).


-------------------------------------------------------------------------------
  SI CA NE MARCHE PAS
-------------------------------------------------------------------------------

  > "ANTHROPIC_API_KEY n'est pas definie"

    Le fichier .env est absent, mal rempli, ou le serveur a ete demarre
    avant sa creation. Verifie .env, puis arrete le serveur (Ctrl + C)
    et relance "npm run dev".
    Le site s'affiche quand meme dans ce cas : seule la generation echoue.


  > "EADDRINUSE" ou "port 3000 already in use"

    Un autre programme occupe le port 3000. Ferme-le, ou lance le site
    sur un autre port :

        npm run dev -- -p 3001


  > Une erreur qui parle de "bindings file" ou d'un fichier ".node"

    Cela signifie qu'un module natif traine encore dans node_modules.
    Le projet n'en utilise plus aucun. Nettoie et reinstalle :

        rm -rf node_modules
        npm install

    Avec pnpm :

        rm -rf node_modules
        pnpm install


  > Le site affiche une erreur apres un "git pull"

    Les dependances ont peut-etre change. Relance :

        npm install


  > L'historique est vide alors que j'avais des textes

    Verifie que le fichier data/generations.json existe et qu'il contient
    bien un tableau JSON valide. S'il est corrompu, le site l'ignore et
    affiche un historique vide, en le signalant dans le terminal.


-------------------------------------------------------------------------------
  BON A SAVOIR
-------------------------------------------------------------------------------

  - Chaque generation appelle l'API Claude avec de la recherche web :
    elle est facturee sur ton compte Anthropic et prend en general
    entre 30 secondes et 2 minutes.

  - Pour plafonner la depense : page Billing de la console Anthropic,
    section "Spend limits".

  - Pour ajouter une categorie ou un type de contenu dans les listes
    deroulantes, edite le fichier :   src/lib/taxonomy.ts

  - Pour changer de modele (et payer moins cher), edite la constante
    MODEL dans :   src/lib/claude.ts
