===============================================================================
  LEARNING — COMMENT LANCER LE PROJET
===============================================================================

Tout se fait dans un terminal, depuis le dossier du projet :

    cd chemin/vers/learning


-------------------------------------------------------------------------------
  CE QU'IL FAUT AVOIR INSTALLE
-------------------------------------------------------------------------------

  - Node.js version 20 ou plus (verifie avec :  node -v  )
  - npm ou pnpm, au choix

  Il n'y a PLUS besoin de cle API. Le site ne fait aucun appel reseau : il
  se contente de lire les textes deja ecrits dans le dossier content/.


-------------------------------------------------------------------------------
  LANCER LE SITE : 2 COMMANDES
-------------------------------------------------------------------------------

  1) Installer les dependances (la premiere fois seulement)

        npm install

  2) Demarrer

        npm run dev

     Puis ouvre :   http://localhost:3000
     Pour arreter : Ctrl + C dans le terminal.

  Les fois suivantes, "npm run dev" suffit. Refais "npm install"
  uniquement apres un "git pull" qui change les dependances.


-------------------------------------------------------------------------------
  REMPLIR LA BIBLIOTHEQUE
-------------------------------------------------------------------------------

  Les textes sont ecrits a l'avance, pas a la demande. Dans une session
  Claude Code ouverte sur ce dossier :

        /generer          ecrit 3 textes
        /generer 5        ecrit 5 textes

  La commande choisit elle-meme les sujets : elle prend la categorie et le
  format les moins representes, evite les titres deja traites, cherche ses
  faits sur le web, ecrit les fichiers, les verifie et les commite.

  Pour en ajouter automatiquement chaque jour :

        /loop 24h /generer 3

  Le site relit le dossier a chaque chargement de page : les nouveaux
  textes apparaissent sans avoir a redemarrer quoi que ce soit.


-------------------------------------------------------------------------------
  TOUTES LES COMMANDES DISPONIBLES
-------------------------------------------------------------------------------

  npm run dev             Serveur de developpement. Celle du quotidien.

  npm run build           Construit la version optimisee du site.

  npm start               Lance la version construite (necessite build).

  npm run check:content   Verifie les fichiers de content/ : format,
                          categories, dates, doublons, URLs des sources.

  npm run lint            Verifie le style du code (ESLint).

  npm run typecheck       Verifie les types TypeScript.


-------------------------------------------------------------------------------
  OU SONT LES TEXTES
-------------------------------------------------------------------------------

  Dans le dossier :   content/

  Un fichier markdown par texte, versionne avec le code. Le nom du fichier
  sert d'adresse : content/2026-09-17-mon-sujet.md est lisible sur
  http://localhost:3000/a/2026-09-17-mon-sujet

  - Pour corriger un texte : edite le fichier, c'est du markdown.
  - Pour en supprimer un : supprime le fichier.
  - Pour en masquer un sans le supprimer : renomme-le avec un _ devant
    (par exemple _2026-09-17-mon-sujet.md).

  Le format exact est explique dans content/README.md.


-------------------------------------------------------------------------------
  SI CA NE MARCHE PAS
-------------------------------------------------------------------------------

  > "EADDRINUSE" ou "port 3000 already in use"

    Un autre programme occupe le port 3000. Ferme-le, ou lance le site
    sur un autre port :

        npm run dev -- -p 3001


  > Un texte n'apparait pas sur le site

    Il est probablement mal forme : le site ignore les fichiers invalides
    au lieu de tomber. Lance :

        npm run check:content

    Il te dira exactement quel fichier et quel champ posent probleme.


  > Une erreur qui parle de "bindings file" ou d'un fichier ".node"

    Un module natif traine encore dans node_modules. Le projet n'en
    utilise plus aucun. Nettoie et reinstalle :

        rm -rf node_modules
        npm install


  > Le site affiche une erreur apres un "git pull"

    Les dependances ont peut-etre change. Relance :

        npm install


-------------------------------------------------------------------------------
  BON A SAVOIR
-------------------------------------------------------------------------------

  - Pour ajouter une categorie ou un type de contenu dans les listes
    deroulantes, edite :   src/lib/taxonomy.ts

  - Pour changer le ton, la longueur ou les exigences de sourçage des
    textes generes, edite :   .claude/commands/generer.md
